# Chapter 9 — From Prompt Templates to Claude Skills

This chapter has one codebase folder:

- `skills/` — the three Claude Skills built in the chapter's mini-project (`concept-explainer`, `code-review`, `learning-loop`), each converted from a template in chapter 8's `../chapter 8/prompt-library/`. See `skills/README.md` for what changed in each conversion.

Chapter 9 doesn't introduce a new app or worked-example project of its own; it takes chapter 8's prompt library and the Probe/Build/Reflect/Catalogue loop and repackages both as skills, so there's no separate `src/` to browse here, just the finished `SKILL.md` files the chapter walks through building.
