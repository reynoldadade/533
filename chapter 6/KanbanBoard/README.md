# Chapter 6 — Kanban Board (Mini Project)

Starting code for "Mini Project: Debug and Refactor a Kanban Board."
This is the intentionally messy version described in the chapter — prop
mutation, no composables, weak event naming, missing validation. Fixing
it is the reader's exercise; nothing here has been corrected.

## Running it

```bash
npm install
npm run dev
```
